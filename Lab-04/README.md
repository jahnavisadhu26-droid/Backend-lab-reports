# Lab 04 - User Registration, Login and JWT

## Technologies Used
- Node.js
- Express.js
- SQLite
- bcrypt
- JSON Web Token

## Features
1. User registration
2. Password hashing using bcrypt
3. Duplicate username validation
4. User login
5. JWT token generation
6. Invalid username and password handling

## Run Project

npm install
node server.js

## API Endpoints

POST /register
POST /login

## Database
users-database.db
